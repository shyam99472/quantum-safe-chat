# Full-Stack Real-Time Chat Application

This is a full-stack real-time chat application built with React, Node.js, Express, Socket.io, and MongoDB. It features a WhatsApp-like user interface, simple username login, 1-to-1 messaging, and file sharing support.

## Project Structure

- `/backend`: Node.js, Express, Socket.io, Mongoose, Multer
- `/frontend`: React (Vite), Context API, Socket.io-client, Axios

## Prerequisites

- Node.js (v16+ recommended)
- MongoDB (Running locally on `127.0.0.1:27017` or change the `MONGO_URI` in `.env`)

## Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies (should already be done if generated by assistant):
   ```bash
   npm install
   ```
3. Create a `.env` file in the `backend/` directory (already created) with:
   ```env
   PORT=5000
   MONGO_URI=mongodb://127.0.0.1:27017/chatapp
   ```
4. Start the backend server:
   ```bash
   npm start 
   # or
   node server.js
   ```

## Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies (should already be done if generated by assistant):
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
